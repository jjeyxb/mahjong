# MIA — 雀魂麻將輔助

[English](README.en.md)

MIA（Mahjong Intelligence Assistant）是一個在你打雀魂時，從旁給建議的桌面程式。它看遊戲畫面或對局資料，告訴你這手該打什麼、手牌離聽牌還有多遠、哪些牌打出去不會放銃。支援 Windows 與 Apple Silicon Mac，網頁版與 Steam 版雀魂都能用。

這是一個大學畢業專題。

> [!WARNING]
> **第三方輔助工具可能違反雀魂的使用條款，帳號有被處分的風險，後果由使用者自行承擔。**
> 本專案為學術研究用途，請用在觀戰、牌譜回放或與電腦對戰，**不要用在排名對局**。詳見[注意事項](#注意事項)。

## 功能

| 功能 | 給你什麼 |
|---|---|
| **AI 建議** | 用 [Mortal](https://github.com/Equim-chan/Mortal) 麻將 AI 算出這一手的建議：切哪張、要不要鳴牌、立直、和了，附上各選項的評分。 |
| **向聽分析** | 讀出你的手牌，算向聽數與每張牌打出後的進張。 |
| **放銃分析** | 只列規則推得出來的資訊：一張牌在現物、筋、壁、振聽排除之後還剩幾種待牌型。不給沒有根據的百分比。 |

- **五種打法風格**：標準，以及本專題微調出來的愛鳴牌、不愛鳴牌、愛立直、不愛立直。可以另外選一種並排比較。
- **網頁版與 Steam 版**：網頁版用內附的瀏覽器開遊戲；Steam 版直接看遊戲畫面。
- **三種辨識方式**：樣板比對、YOLO、混合辨識，在各功能的設定頁切換。
- **Overlay**：建議可以直接疊在牌桌上顯示，全螢幕遊戲也看得到。
- **介面語言**：繁體中文、English。

三個功能各有一個開關，互相獨立，只開需要的就好。

## 系統需求

- **Windows**：64 位元（x64）。
- **Mac**：Apple Silicon（M 系列晶片）。Intel Mac 不支援。
- **硬碟空間**：安裝後約 3 GB（模型與瀏覽器都包在裡面）。
- 安裝包已包含所有需要的東西，**不用另外安裝 Python 或其他工具**。

## 下載與安裝

到 [Releases](https://github.com/jjeyxb/mahjong/releases) 下載對應的安裝檔。目前是內測版，安裝檔沒有經過 Microsoft 或 Apple 的簽章。

### Windows

1. 下載 `MIA-<版本>-windows-x64-setup.exe`（只有這一個檔）。
2. 執行安裝檔。如果出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
3. 選擇安裝位置。預設是 `%LOCALAPPDATA%\Programs\MIA`，不需要系統管理員權限。請選一個 MIA 專用的空資料夾。
4. 從開始功能表或桌面捷徑開啟 MIA。

### Mac

1. 下載 `MIA-<版本>-macos-arm64.dmg`，雙擊打開。
2. 把 **MIA.app** 拖到旁邊的 **Applications**（應用程式）資料夾。
3. 從「應用程式」開啟 MIA。不要直接在磁碟映像裡執行，那樣無法自動更新。
4. 如果系統說「無法驗證開發者」，到「系統設定 → 隱私權與安全性」，往下找到 MIA，按「仍要打開」。

### 更新

「一般設定 → 語言與更新」裡按「檢查更新」。更新只會換掉程式本身，設定、登入資料與錄影都會保留。

## 開始使用

MIA 開啟後，側邊視窗會出現在螢幕右側。三個功能預設都是關的。

**先到「一般設定 → 遊戲版本」選你玩的是網頁版還是 Steam 版。** 選錯的話，MIA 會說找不到遊戲視窗。

### 網頁版

1. 按側邊視窗左下角的 **「開始遊戲」**，MIA 會開一個內附的瀏覽器並載入雀魂。
2. 在這個瀏覽器裡登入雀魂。登入狀態會保存在本機，下次不用再登入。
3. 進入對局後，撥開你要的功能：AI 建議、向聽分析、放銃分析。

### Steam 版

1. 自己從 Steam 開啟雀魂。Steam 版不用按「開始遊戲」，那顆按鈕會是停用的。
2. 在「一般設定 → 遊戲版本」選 **Steam 版**。
3. Mac 用全螢幕玩的話，版面已經量好，可以直接用。其他視窗大小要框一次手牌：進一場對局，在手上**沒有副露**時，到「向聽分析 → 設定 → 框選手牌範圍」，大致框住自己的手牌就好，程式會自動對齊。框過一次會記住。
4. 撥開要用的功能。Steam 版三個功能都靠畫面辨識。
5. Mac 全螢幕時，遊戲在另一個桌面，看不到側邊視窗。到「一般設定」勾 **「在遊戲上顯示 Overlay」**，建議會直接疊在牌桌上。

### Mac 的螢幕錄製權限

第一次開啟需要看畫面的功能時，macOS 會要求螢幕錄製權限。到「系統設定 → 隱私權與安全性 → 螢幕錄製」允許 **MIA**，然後**完整結束 MIA 再重新開啟**，權限才會生效。

### 常用設定

| 位置 | 用途 |
|---|---|
| AI 建議 → 設定 → 打法風格 | 換一種風格的 AI。換的時候約半秒沒有建議。 |
| AI 建議 → 設定 → 比較對象 | 多載一種風格並排比較。運算量與記憶體都是兩倍。 |
| 各功能 → 設定 → 畫面辨識方式 | 樣板比對、YOLO 或混合辨識。三個功能頁的這個選項是同一個設定。 |
| 一般設定 → YOLO 運算裝置 | YOLO 用 CPU 或 GPU 跑。 |
| 一般設定 → 語言與更新 | 介面語言（重新啟動後生效）、檢查更新、清除所有資料。 |

## 注意事項

### 雀魂使用條款

- 第三方輔助工具可能違反雀魂的使用條款。軟體的開源授權只規範程式碼怎麼流通，**不代表你可以拿它連線遊戲**。
- 帳號被警告、停權等風險由使用者自行承擔。
- 本專案為學術研究用途。請用在觀戰、牌譜回放或與電腦對戰，**不要用在排名對局**。

### 建議只是參考

- AI 建議與畫面辨識都可能出錯。MIA 對局面沒把握時會先不給建議，並在視窗底部說明原因，但不保證每次都抓得到錯誤。
- 放銃分析只列規則推得出來的資訊，不代表沒列出的牌就危險，也不代表打了一定安全。

### 遊戲外觀請用預設

- 樣板比對與 YOLO 都是用雀魂**預設的牌面、牌桌與牌背**做出來的。換了造型，辨識可能失準，甚至完全認不到牌。
- 切到 YOLO 或混合辨識時，MIA 會提醒一次。

### 效能

- Mac 的 YOLO 使用 Apple GPU。
- Windows 的 YOLO 預設用 CPU，比較慢。到「一般設定 → YOLO 運算裝置」選 GPU，MIA 會依顯示卡從官方來源下載對應的加速元件（NVIDIA、AMD RX 7700 以上與 RX 9000 系列、Intel Arc；約 1.4~2.8 GB），每個檔都核對雜湊。目前只在 AMD RX 9070 上實測過。
- 不想下載的話，畫面辨識選「樣板比對」比較輕。

### 隱私與資料

MIA 不會把你的資料傳到別處。設定、雀魂登入資料、錄影與紀錄都只存在你的電腦上：

| | Windows | Mac |
|---|---|---|
| 設定、登入資料、錄影 | 安裝資料夾裡的 `userdata\` | `~/Library/Application Support/MIA` |
| 快取 | `userdata\cache\` | `~/Library/Caches/MIA` |
| 紀錄 | `userdata\logs\` | `~/Library/Logs/MIA` |

### 解除安裝

- **Windows**：「設定 → 應用程式 → 已安裝的應用程式」找到 MIA，按「解除安裝」。過程中會問要不要一併刪除設定、登入資料、錄影與紀錄。
- **Mac**：
  1. 想連資料一起刪的話，先在 MIA 的「一般設定 → 語言與更新」按「清除所有資料…」。MIA 會結束並刪掉上表三個資料夾。
  2. 把「應用程式」裡的 MIA.app 丟到垃圾桶。
  3. 到「系統設定 → 隱私權與安全性 → 螢幕錄製」選 MIA，按「－」移除。

## 常見問題

**按了開關，卻一直沒有建議。**
先看側邊視窗底部的狀態訊息，它會說 MIA 在等什麼，例如「等待對局開始」、「事件流對不上，先不給建議」。也可以在「一般設定 → 事件流 Log」打開紀錄視窗，看 MIA 讀到了哪些事件。

**MIA 說找不到遊戲視窗。**
確認「一般設定 → 遊戲版本」選對了。網頁版要用「開始遊戲」開出來的那個瀏覽器，不能用你自己的瀏覽器。

**Mac 上一直跳出螢幕錄製權限提示。**
在系統設定授權之後，要完整結束 MIA 再重新開啟。如果清單裡沒有 MIA，按「＋」把「應用程式」裡的 MIA.app 加進去。

**Mac 的 Dock 圖示還是舊的。**
Finder 會快取圖示。把 MIA.app 移出「應用程式」再放回去，或登出再登入。

## 從原始碼執行

給想修改程式或自己建置的人。需要 Python 3.14（主程式）、Python 3.12（AI 引擎與 YOLO）與 Rust（編譯 Mortal 的 libriichi）。

```bash
git clone https://github.com/jjeyxb/mahjong.git
cd mahjong
python3.14 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python tools/fetch_models.py     # 下載模型權重，逐檔核對 SHA-256
.venv/bin/python tools/ui.py --live
```

AI 引擎與 YOLO 各自要一個 Python 3.12 環境，完整步驟與 Windows 的指令見下列文件：

- [docs/development.md](docs/development.md)：從原始碼安裝、架構、各階段的實測數據（舊版 README）
- [docs/handoff.md](docs/handoff.md)：專案現況與接手須知
- [docs/live.md](docs/live.md)：即時模式操作手冊與狀態訊息對照
- [docs/yolo.md](docs/yolo.md)：YOLO 辨識環境
- [packaging/README.md](packaging/README.md)、[packaging/windows/README.md](packaging/windows/README.md)：打包與發布

## 關於這個專題

- **架構**：主程式（PySide6）負責畫面與辨識；Mortal 與 YOLO 各在獨立的子程序裡跑，用 MJAI 協定溝通。三個功能刻意互不依賴，任何一個出問題都不影響另外兩個。
- **打法風格微調**：目前常見的麻將 AI 打法高度相似。本專題從高段玩家的牌譜中，沿「副露率」與「立直率」兩條風格軸各取兩端，微調出四個模型。風格確實轉移了：副露率重現了 81%、立直率重現了 98% 的差距，平均順位沒有變差。
- **放銃分析**：不靠牌譜統計的放銃率，只輸出能從規則推論出來的東西，每一條都說得出根據。

設計理由與完整數據見 [docs/development.md](docs/development.md) 與 [docs/decisions.md](docs/decisions.md)。
